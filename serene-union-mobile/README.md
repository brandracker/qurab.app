# 📱 Serene Union Mobile (Archived Expo Prototype)

> [!NOTE]
> **This folder contains an early standalone Expo React Native prototype.**
> The active, production mobile deployment for Serene Union is managed inside **[`serene-union-app`](../serene-union-app/)** using **Capacitor Android** (`serene-union-app/android/`).
> 
> - **Production Mobile App**: Built directly from `serene-union-app` via `@capacitor/android` and GitHub Actions (`.github/workflows/build-apk.yml`).
> - **Backend Integration**: The active app connects to the Cloudflare Workers API (`server/`) and Cloudflare D1 SQL database.
> - **Status**: This Expo directory is retained for UI reference only and is not deployed to app stores.
